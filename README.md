# Clock Studio

A light Windows app with 63 desktop clock styles (analog, digital, 7-segment, flip, rings, bars, world clocks, moon phase and more) and full control over every part: shape (22), size to the pixel, background (solid, gradient, glass, acrylic), a separate color for hours, minutes, seconds, separator, date, ticks, numbers, dial, ring, dot and more, fonts, text effects, hand shapes and lengths, time zones, update speed.

Run ClockStudio.exe. Right-click a clock for the menu, left-click the tray icon to add, restore or hide clocks. Starts with Windows by default (turn off in the menu).
Needs Windows 10/11 with .NET Framework 4.8 (already included).
